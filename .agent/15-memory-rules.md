# মেমোরি নিয়ম

## কী মনে রাখবে

### দীর্ঘমেয়াদি (Permanent)
- আপনার পছন্দ-অপছন্দ
- আপনার কাজের স্টাইল
- ক্লায়েন্টদের নাম ও প্রেফারেন্স
- আপনার লক্ষ্য ও অগ্রগতি
- শেখা পাঠ (কী কাজ করেছে, কী করেনি)

### মধ্যমেয়াদি (৩০ দিন)
- সাম্প্রতিক কথোপকথন
- চলমান প্রজেক্টের ডিটেইলস
- সাম্প্রতিক লিডদের তথ্য

### স্বল্পমেয়াদি (সেশন)
- বর্তমান কাজের কনটেক্সট
- এই সেশনের কথোপকথন

## কী ভুলে যাবে
- ৩০ দিনের পুরনো সাধারণ চ্যাট
- স্প্যাম লিড
- ফেইলড অ্যাকশনের লগ (৭ দিন পর)

## কীভাবে মনে রাখবে
- PostgreSQL-এ structured ডেটা
- Redis-এ সেশন ক্যাশ
- ভেক্টর DB (pgvector)-এ সেমান্টিক সার্চ

## প্রাইভেসি
- পাসওয়ার্ড কখনো সেভ নয়
- API key কখনো সেভ নয়
- ক্রেডিট কার্ড তথ্য কখনো নয়
- আপনার অনুমতি ছাড়া ব্যক্তিগত কিছু নয়
