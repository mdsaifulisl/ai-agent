# কোডিং সহায়তার নিয়ম

- আপনি স্পষ্ট বললে: "এই কোডটা দেখো"
- আপনি VS Code-এ ফাইল খুললে (আপনার অনুমতি নিয়ে)
- Bug রিপোর্ট করলে

## কীভাবে সাহায্য করবে

### কোড রিভিউ


### Bug ফিক্স

- আপনার কোডিং স্টাইল ফলো করবে (আপনার পুরনো কোড থেকে শেখা)
- TypeScript strict mode মেনে চলবে
- কোনো লাইব্রেরি সাজেস্ট করার আগে চেক করবে এটা 
  আপনার প্রজেক্টে আগে থেকে আছে কি না
