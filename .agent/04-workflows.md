# দৈনিক ওয়ার্কফ্লো

## সকাল ৯:০০ — মর্নিং ব্রিফ
1. আজকের মিটিংগুলোর তালিকা
2. গুরুত্বপূর্ণ মেসেজ (যদি থাকে)
3. আবহাওয়া (ঢাকা)
4. আজকের ফোকাস সাজেশন

**আউটপুট**: Telegram-এ সংক্ষিপ্ত মেসেজ

## সকাল ১০:০০ — লিড হান্ট
1. LinkedIn-এ নতুন পোস্ট স্ক্যান
2. রেলিভেন্ট ক্লায়েন্ট খোঁজা (স্কোরিং: ০-১০)
3. ৮+ স্কোর হলে → ডেটাবেসে সেভ
4. ১০ স্কোর হলে → সাথে সাথে আপনাকে জানানো

## দুপুর ১২:০০ — সোশ্যাল পোস্ট
1. আজকের কনটেন্ট আইডিয়া জেনারেট
2. LLM দিয়ে পোস্ট লেখা
3. আপনাকে Telegram-এ অ্যাপ্রুভালের জন্য পাঠানো
4. অ্যাপ্রুভ হলে LinkedIn + Facebook-এ পোস্ট

## বিকেল ৩:০০ — মেসেজ রিপ্লাই
1. সব প্ল্যাটফর্ম থেকে আনরিড মেসেজ সংগ্রহ
2. ক্যাটাগরি: ক্লায়েন্ট / লিড / বন্ধু / স্প্যাম
3. ক্লায়েন্ট+লিড → ড্রাফট রিপ্লাই তৈরি → আপনার অ্যাপ্রুভাল
4. বন্ধু → সরাসরি রিপ্লাই (আপনার স্টাইলে)

## সন্ধ্যা ৭:০০ — ইনবক্স ক্লিনআপ
1. যা যা রিপ্লাই হয়েছে → ডেটাবেসে লগ
2. কে রিপ্লাই দেয়নি → রিমাইন্ডার সেট
3. স্প্যাম → রিপোর্ট

## রাত ১০:০০ — দৈনিক রিপোর্ট
Google Sheets-এ লিখবে:
- মোট মেসেজ রিপ্লাই: X
- নতুন লিড: Y
- লিড কনভার্শন: Z%
- পোস্ট করা হয়েছে: A
- আজকের আয়: B
- আগামীকালের মিটিং: C
- পরামর্শ: D
