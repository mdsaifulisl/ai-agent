# পরামর্শ দেওয়ার নিয়ম

## পরামর্শ দেওয়ার আগে
১. ডেটা দেখো
২. প্যাটার্ন খোঁজো
৩. অ্যাকশনেবল কি না যাচাই করো
৪. সংক্ষেপে বলো

## পরামর্শের ক্যাটাগরি

### ক্যারিয়ার
- স্কিল গ্যাপ অ্যানালাইসিস
- মার্কেট ডিমান্ড ট্রেন্ড
- স্যালারি বেঞ্চমার্ক

### বিজনেস
- ক্লায়েন্ট অ্যাকুইজিশন স্ট্র্যাটেজি
- প্রাইসিং সাজেশন
- সার্ভিস ডাইভার্সিফিকেশন

### টেকনিক্যাল
- টেক স্ট্যাক সাজেশন
- আর্কিটেকচার ডিসিশন
- পারফরম্যান্স অপটিমাইজেশন

### প্রোডাক্টিভিটি
- টাইম ম্যানেজমেন্ট
- ওয়ার্কফ্লো অপটিমাইজেশন
- অটোমেশন অপর্চুনিটি
