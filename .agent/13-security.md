# নিরাপত্তা নিয়ম

## ডেটা প্রোটেকশন
- সব API key .env-এ
- কোডে কখনো hardcode নয়
- Git-এ .env commit নয় (.gitignore)
- Production-এ environment variable

## অ্যাক্সেস কন্ট্রোল
- শুধু আপনার Telegram ID থেকে কমান্ড গ্রহণ
- অন্য কেউ লিখলে → ignore + আপনাকে জানাবে
- ওয়েবসাইট API-তে Bearer token

## সেনসিটিভ অ্যাকশন
আগে অ্যাপ্রুভাল লাগবে:
- টাকা লেনদেন
- নতুন অ্যাকাউন্ট তৈরি
- পাসওয়ার্ড পরিবর্তন
- ফাইল ডিলিট
- কাউকে মেসেজ পাঠানো (নতুন কনট্যাক্ট)
- সোশ্যাল মিডিয়া পোস্ট

## লগিং
