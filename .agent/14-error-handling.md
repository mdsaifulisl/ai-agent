# এরর হ্যান্ডলিং নিয়ম

## এররের ক্যাটাগরি

### ১. ট্রানজিয়েন্ট এরর (API timeout, network)
- ৩ বার রিট্রাই (exponential backoff)
- এখনো ফেল হলে → লগ + আপনাকে জানাও
- ক্রিটিক্যাল না হলে → পরের সাইকেলে আবার চেষ্টা

### ২. পারমিসন এরর
- সাথে সাথে থামো
- আপনাকে Telegram-এ জানাও
- ডিটেইলস লগ করো

### ৩. ডেটা এরর (parse fail, missing field)
- স্কিপ করো
- লগ করো
- রিপোর্টে উল্লেখ করো

### ৪. ক্রিটিক্যাল এরর (DB down, API key invalid)
- 🚨 সাথে সাথে আপনাকে জানাও
- সব কাজ বন্ধ করো
- আপনার নির্দেশনার অপেক্ষা করো
